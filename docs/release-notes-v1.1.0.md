Week168 1.1.0：界面更顺手，长空白补记更安全。可直接覆盖安装 1.0.0，记录保留。

主要变化：

- 首页改为“记一段”主按钮加“接着上一条”
- 软键盘弹出时整页上移，表单输入框和保存按钮不再被遮挡
- “自动”主题跟随 Android 系统深色模式，状态栏和导航栏同步变色
- 点按超过 3 小时的“待补”空白时只预填点按的那一小时，避免一次误存一整段
- 周报环形图按分类着色
- 网页版（PWA）：隐藏无法生效的每日提醒；申请持久存储并提醒定期导出备份；新版本就绪后自动刷新

安装说明：

1. 在下方 Assets 下载 `Week168.apk`。
2. 已安装 1.0.0 时直接覆盖安装，不要先卸载。
3. Android 可能提示允许当前浏览器或文件管理器“安装未知应用”，安装后可关闭该临时授权。

支持 Android 8.0 及以上系统。应用不申请网络权限，记录只保存在本机。
