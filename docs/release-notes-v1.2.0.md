Week168 1.2.0：新增可选的健康追踪，并修复导入备份。可直接覆盖安装 1.1.0 或 1.0.0，记录保留。

主要变化：

- 新增健康追踪（默认关闭，在设置中开启）：用药计划与下一针倒计时、注射记录与部位轮换、体重趋势
- 注射日本地提醒：独立通知渠道，通知不含药物名称，锁屏只显示通用提示
- 本机估算药物残留水平，仅供参考；应用不推荐剂量，也不提供治疗建议
- 健康数据单独存储、单独备份；时间记录和原有备份格式不变
- 修复：1.1.0 中选好备份文件后导入没有反应
- 确认框改为系统样式，跟随浅色/深色主题

安装说明：

1. 在下方 Assets 下载 `Week168.apk`。
2. 已安装 1.1.0 或 1.0.0 时直接覆盖安装，不要先卸载。
3. Android 可能提示允许当前浏览器或文件管理器“安装未知应用”，安装后可关闭该临时授权。

支持 Android 8.0 及以上系统。应用不申请网络权限，记录只保存在本机。
