Week168 的首个公开版本：一款完全离线、无账号、无广告的 Android 每周时间账本。

主要功能：

- 15 分钟精度的 24 小时时间轴，支持跨午夜记录
- 拖选时段、续接上一条、重叠自动拆分与撤销
- 7 × 24 周视图、通用周报和历史回看
- 自定义分类、深浅主题和每日本地提醒
- 完整 JSON 备份、严格恢复校验与异常数据保护
- 已适配 Android 15/16 系统栏、刘海和手势导航安全区
- 时间轴到底后页面可继续滚动，20:00–24:00 完整可达

安装说明：

1. 在下方 Assets 下载 `Week168.apk`。
2. Android 可能提示允许当前浏览器或文件管理器“安装未知应用”，这是 GitHub 侧载安装的正常提示。
3. 安装后可关闭该临时授权。

支持 Android 8.0 及以上系统。应用不申请网络权限，记录只保存在本机。卸载或清除应用数据前，请先在“设置 → 备份与恢复”导出 JSON。
